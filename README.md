Hello and thank you for playing my game!

WASD or arrow controls to move.
W / up / spacebar to jump.
S / down to fast fall once jump is descending
Shift + movement to run
Ctrl + movement to dash

Jump onto a wall to hold on, jump again to wall-jump
Snails and spikes are enemies.
Springs, ice blocks, and gravity wells will change player movement properties
Apples will add to score, but reset upon death. There are 12 total at this point.'
3 levels currently exist.

Have fun and let me know of any gameplay / code suggestions!
